# IDsanna

Agente multimodal para Android, web, navegador, Termux y automatización supervisada.

## Objetivo

Construir una plataforma que reciba instrucciones por texto y voz, coordine agentes especializados, controle capacidades autorizadas de Android y navegador, ejecute tareas seguras en Termux y ayude a crear MVPs y código.

## Principios

- Acciones visibles y supervisadas.
- Permisos comprobados antes de ejecutar.
- APIs oficiales antes que automatización visual.
- Verificación del resultado y recuperación por checkpoints.
- Sin acceso arbitrario a datos privados ni evasión de protecciones.

## Componentes previstos

- Android Agent
- Gateway y orquestador
- Web Control Panel
- Browser Agent
- Termux CLI
- Model Router
- Agentes especializados
- Motor de permisos y aprobaciones
- Verificación de acciones
- Constructor de MVPs
